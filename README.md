## 📖 Sobre el proyecto

Portafolio **cinematográfico y responsive** enfocado en automatizaciones con IA. La experiencia usa fotografías independientes para móvil y escritorio, transiciones entre escenas, profundidad, iluminación ambiental y movimiento sutil de cámara controlado desde la interfaz.

> 💡 **Diferencia clave:** cada proyecto mostrado aquí existe en producción real — no son demos teóricos.

### ✨ Características

| | |
|---|---|
| 🎬 | **Experiencia inmersiva** — entrada en un estudio nocturno con cámara parallax al mover el cursor |
| 🖥️ | **Responsive real** — escenas y layouts distintos para escritorio horizontal y móvil vertical |
| 🖼️ | **Assets optimizados** — imágenes WebP con los PNG originales conservados como fuente |
| 📱 | **Evidencia real** — capturas oficiales de apps publicadas y flujos en operación |
| 📄 | **CV descargable** — PDF integrado en la interfaz |

<summary><b>🔍 Detalle de cada sistema</b></summary>

### 01 · Solicitudes legales
El equipo legal invertía horas en redactar documentos repetitivos y comprobar formatos institucionales. El sistema estandariza **cinco tipos de solicitudes** y entrega documentos listos para revisión profesional.

**Flujo:** Datos del caso → Validación automática → Documento preparado → Revisión profesional

### 02 · Plásticos Duralón
Los pedidos dependían de llamadas y del horario comercial. Los clientes ahora consultan catálogo y precios, preparan cotizaciones y envían pedidos **a cualquier hora**, integrados con el ERP sin exponer código corporativo.

**Responsabilidad end-to-end:** UX, desarrollo móvil, backend, integración ERP, publicación en tiendas y mantenimiento.

### 03 · Inventario multi-tienda
API multi-tenant con autenticación JWT, permisos por rol, movimientos trazables, pruebas, migraciones y despliegue con Docker.

</details>

## ⚡ Inicio rápido

```bash
# Clonar
git clone https://github.com/yeisondev001/ai-automation-portfolio.git
cd ai-automation-portfolio

# Instalar dependencias
npm install

# Servidor de desarrollo → http://localhost:5173/
npm run dev
```

### 📋 Scripts disponibles

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo con HMR |
| `npm run build` | Verificación de tipos + build de producción |
| `npm run preview` | Previsualiza el build de producción |
| `npm run lint` | Lint con Oxlint |

## 🗂️ Estructura del proyecto

```
src/
├── assets/
│   ├── room/          # Escena de entrada (desktop + móvil)
│   ├── cinematic/     # Escenas de automatización y perfil
│   └── projects/      # Capturas de los sistemas (duralon-app, legal-system)
```
